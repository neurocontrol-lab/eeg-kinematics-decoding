# EEG–EMG–Kinematics workspace

- `hand_motion_eeg/`: Git repository for code, protocols, saved results and presentation links. Start with its `README.md`.
- `data/raw/way-eeg-gal/P1` … `P12`: original participant recordings.
- `data/external/way_eeg_clean/`: downloaded reduced Kaggle data with partly undocumented preprocessing.
- `references/papers/`: dataset paper and literature PDFs.

Data and reference PDFs are local workspace material outside the repository. Configure alternative data locations with `hand_motion_eeg/configs/paths.local.toml` or the documented environment variables. Temporary material is archived in `hand_motion_eeg/tmp/`.
