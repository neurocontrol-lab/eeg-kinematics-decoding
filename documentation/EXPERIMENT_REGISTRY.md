# Experiment registry

The public [Google Sheet](https://docs.google.com/spreadsheets/d/1Q2nJqr66ftuz7CP9dMiYRdE2RGwavmGbMGDkOS7yiWg/edit) is the single maintained experiment registry and roadmap. Edit statuses, priorities, findings and next decisions there.

Protocols, code, detailed reports and immutable execution snapshots remain in this repository. This page only preserves navigation from older saved reports; it contains no local registry copy.

Experiment IDs use `CATEGORY_number`, with numbering starting at 1 in each category. The prefixes are `B` (baseline), `C` (conditions and stages), `E` (pipeline and evaluation), `M` (modalities and extensions), `P` (participant transfer), `R` (saved-decoder results), and `T` (timing and targets). The backlog retains its idea labels. Archived run reports and code snapshots may display historical identifiers.
