# C_10 — Stage-specific EEG weight decoding on repeat and switch trials

- Use all 12 participants at fixed sandpaper, with separate models. Train on each participant’s two weight series in 1–6, validate on 7, and test on 8–9. Exclude the first trial of each series from history analyses and confirm previous labels against chronological adjacency.
- Match trials across preparation (LED on to hand start), reach (hand start to first contact), loading (both digits start loading to lift-off), and lift/hold (lift-off to lowering cue). Use a fixed, centered 32-sample EEG segment (64 ms at 500 Hz), chosen from metadata coverage before fitting. This is a retrospective stage analysis. Exclude invalid event order or trials too short in any of the four stages, and count the resulting coverage by class and group.
- Compare shrinkage LDA and multinomial logistic regression on shared per-channel segment mean and standard deviation features. Use training-only EEG and feature scaling. LDA uses automatic shrinkage and equal class priors. Logistic penalty uses series 7 balanced accuracy over C=0.01/0.1/1/10, with ties to lower C. Both neural models use the same standardized 32×32 EEG. Adapt the existing CNN + ELU and CNN–BiLSTM to the 32-sample input and three-weight softmax. Train each with seed 42, Adam, class-balanced weights, batch 16 and fixed 15 epochs. Score one output per trial per stage.
- Use all matched training repeats and switches in each fit. Compare held-out trial balanced accuracy separately for repeats and switches. Primary readout is the probability of actual minus previous weight on switch trials, averaging all six directed transitions equally within participant and then participants equally. Report preparation, reach, loading and lift/hold and the paired loading-minus-reach and lift/hold-minus-preparation changes. Resample participants for descriptive 95% intervals, conditional on this split. Assess direction and prior streak length as descriptive secondary results, comparing repeats and switches within history lengths 1–3 when both occur. Report counts with every subgroup result.
- Controls include uniform chance, a previous-weight rule and a cohort lookup from trial number and previous weight fitted on training metadata only. Also compare a stage-duration-only classifier as a retrospective timing control. The EEG classifiers receive none of these metadata. Repeat and switch status align with trial number across the weight series. A stage-specific result cannot separate expectation from serial carryover or learned schedule; post-contact discrimination can include kinematics or artifacts.

## Execution

Neural fits used Keras 3.9.2 with PyTorch 2.7.1 on CPU because the local TensorFlow runtime could not load. Run from the repo root with a scratch directory using extract.py, run.py (linear and neural modes), then summarize.py with the condition-audit trial CSV, and verify.py. The pre-existing dataset audit and model definitions are loaded from their repository paths.
