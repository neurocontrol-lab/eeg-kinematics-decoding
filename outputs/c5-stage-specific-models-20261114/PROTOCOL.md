# C_5 — Ridge and CNN stage-specific wrist decoders

Use the original verified C_5 trial clocks, training series 1–6 and held-out series 8–9 for P1–P12. Use the same 256 ms EEG windows, 2 ms prediction lead, target indices and training scalers. Ridge retains both window rules and the original specialist and full-pooled MSEs. Sample-matched ridge controls are recomputed with 64-bit recording-series and condition keys, with five fixed draws per stage. Add CNN + ELU, EEGNet regression and CNN–BiLSTM using the pure-stage rule. Give each CNN 15 Adam epochs at batch size 64 with seed 42. Use the existing wrist-position architectures. Hold model settings fixed across full pooled, specialists and sample-matched pooled models.

Train a separate specialist per participant, architecture and eligible stage. Score it on every supported evaluation stage. Fit a full pooled model per participant and architecture and evaluate by stage. For each supported matching stage, fit a pooled model matched exactly to the specialist's training-window count and recording-series × weight × surface counts. CNN matched subsampling uses seed 42. The original ridge reports average the five matched draws. Score matched CNN controls on their comparison stage. Stage mean and pooled mean are non-EEG baselines. Record model scope separately.

Within each participant and test stage, weight each trial equally and weight windows equally within a trial. Axis R² uses the trial-weighted mean observed position for that test stage and axis as its constant reference. Mean XYZ R² averages the three axis scores. If any axis has effectively zero variance, leave that R² and its XYZ mean undefined. Across participants and stages use equal weights. Primary balanced comparison uses the strict-rule stages with common support for all twelve participants and all model scopes. Stage-level summaries report available participants. R² can be strongly negative when a stage's wrist position barely varies. Report both R² and MSE, with split-specific results distinct from transfer or real-time routing.

Train CNNs on GPU and record the device. This is a single-seed architecture comparison with exploratory participant bootstrap intervals.

The GPU implementation reuses TensorFlow graphs with XLA disabled. Before each fit it resets layer weights, optimizer variables and layer random states. Training order is shuffled with the fixed seed per fit. The trial and condition keys are widened before arithmetic to avoid NumPy integer overflow.
