# C_10 — Full-stage EEG representation

Use the same four event-delimited stages, P1–P12 participant-specific models, previous-weight labels, two weight-series training sets per person, validation series 7 and held-out series 8–9 as the original C_10 run. Retain exactly the original 775 training, 382 validation and 769 test trials. Train separately for each participant and stage, using training-only scaling.

Partition all samples between the start (inclusive) and end (exclusive) stage markers into 32 consecutive bins with integer boundaries floor(k × sample count / 32). Average the input signal separately for each of the 32 channels in each bin. This preserves stage-relative order. Time resolution in milliseconds varies with trial duration. CNN + ELU and CNN–BiLSTM receive that 32 × 32 input, with the original C_10 classifier layer stacks, seed 42, Adam, class-balanced weights, batch size 16 and 15 epochs. Both use Keras with the PyTorch CPU backend. For shrinkage LDA and multinomial logistic regression, compute channel means and standard deviations of the eight bin means in each of four consecutive quarters, giving 256 features. The original crop used 64 features for these same two models. This contrasts two feature representations, including changes in dimensionality for the linear models and time normalization for all models.

Compare the same validation-tuned logistic regression with duration alone versus the 256 EEG features plus duration. Evaluate this added-value contrast on balanced accuracy and multiclass log loss.
