# C_5 — Stage-specific versus pooled kinematics decoding

- Use P1–P12 within participant. Reuse verified T_1 EEG/target scalers and target grids. Fit on series 1–6. Hold series 8–9 for all performance comparisons. Fix the prediction lead at 2 ms and use the existing 256 ms EEG window. Use each participant’s T_1 validation-selected 2 ms ridge penalty for every fit.
- Verify the EEG and wrist clocks against raw trial files. Evaluate the eight event-defined stages separately using identical targets for all models within a stage and analysis. Primary analysis includes targets whose whole EEG window is in the target stage and trial. The sensitivity analysis labels by target stage and permits preceding-phase context.
- Train an all-stage ridge, a ridge per supported stage, and five pooled ridge fits per stage with the same training-window count and exact recording-series × weight × surface counts as that specialist. Sample pooled windows without replacement using fixed seeds 42–46. Include constant pooled and stage-specific wrist means. Only train specialists with at least 20 eligible windows across at least eight trials. Only score test stages with at least five trials.
- Compute XYZ mean squared error in training-standardized wrist coordinates. Within each participant, average errors within each trial before averaging across trials. Average sample-matched controls across seeds. Compare each specialist on each supported test stage with the full pooled model on the same targets. For diagonals, also compare with matched pooled ridge and the stage mean. Report participant support and exploratory paired participant-bootstrap intervals. For a summary across stages, average stage-level differences within each participant using supported stages, then average across participants.
- Stage composition, position variance and median wrist speed (82 ms derivative estimate) are reported from the matched evaluation windows. The comparison is retrospective and assumes stage labels are known. These models test stage specialization with ridge; different results may arise with nonlinear decoders. The test series were reused from T_1, and exploratory intervals are conditional on this dataset and split.
